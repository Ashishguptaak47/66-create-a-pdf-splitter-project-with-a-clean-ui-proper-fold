# Python PDF Splitter

A clean, modern desktop application built with CustomTkinter to split PDF documents by page ranges or individual pages.

## Features
- Modern Dark/Light UI using CustomTkinter
- Split by specific page numbers or ranges (e.g., `1-3, 5, 7-10`)
- Split every single page into separate PDFs
- Automatic output directory management

## Installation
```bash
pip install -r requirements.txt
```

## Running the App
```bash
python main.py
```

## Running Tests
```bash
pytest
```
